## 🧠 Overview

Adobe Photoshop is a Windows image editing application built around a non-destructive layer stack. Raster and smart-object layers, masks, adjustment layers and layer styles let retouchers and designers change a composition at any stage without flattening the source pixels, while the document model keeps selections, channels, paths and alpha data alongside the artwork.

The workspace combines selection and masking tools, brush-based painting, text and vector shape layers, camera raw processing and a configurable export pipeline. Depending on the project, users work with frequency separation for skin, luminosity masks for tonal control, smart filters for re-editable effects, or generative fill and content-aware operations for reconstruction of image areas.

## Additional Information for Windows Users

Photoshop documents keep the full layer stack, so file size grows with resolution, layer count and smart objects rather than with the visible image alone. A dedicated scratch disk and enough RAM keep history states and filter previews responsive on large canvases; performance on a given system depends on document resolution, GPU acceleration and the number of active effects.

Brush, selection and retouch workflows can be automated through actions and presets, which makes repetitive editing and batch export predictable. Print output depends on document color profile, bit depth and resolution settings, so export presets are usually kept per target platform instead of being changed globally.
